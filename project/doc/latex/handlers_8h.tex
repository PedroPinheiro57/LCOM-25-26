\doxysubsection{Detailed Description}
Top-\/level interrupt and event dispatch stubs. 

Each function is called from the main event loop whenever the corresponding interrupt bit fires. They read raw hardware data, update the relevant device model (keyboard, mouse, UART), and then forward the decoded event to the game controller via the game\+\_\+handle\+\_\+\texorpdfstring{$\ast$}{*} family of functions.

These are thin glue routines; all game logic lives in \doxylink{game_8h}{controller/game.\+h}.
