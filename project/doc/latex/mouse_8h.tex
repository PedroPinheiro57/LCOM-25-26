\doxysubsection{Detailed Description}
PS/2 mouse packet parsing and cursor-\/state tracking. 

Decodes the three-\/byte PS/2 mouse packets into a high-\/level \doxylink{structmouse__state__t}{mouse\+\_\+state\+\_\+t} that the rest of the game reads each tick.
