Detailed Description

Board and HUD rendering, sprite management, and explosion effects.

Owns the lifetime of all in-game sprite and animated-sprite objects and exposes the drawing routines used by game_draw to compose each frame.

The renderer maintains a small state machine for the post-attack explosion animation: start_explosion kicks it off, update_animations advances it each tick, and renderer_explosion_finished signals when the sequence is complete so the game can resume input.
