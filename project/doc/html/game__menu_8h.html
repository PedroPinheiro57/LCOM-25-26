Detailed Description

Menu and overlay rendering for all non-gameplay screens.

Provides drawing routines for the main menu, pause menu, game-over screen, player-handover overlay, and the instructions screen, together with hit-testing helpers that map a mouse position to the highlighted menu option.

Layout constants define where the option buttons are rendered so that the same values can be shared between the draw and hit-test routines.
