Detailed Description

Top-level interrupt and event dispatch stubs.

Each function is called from the main event loop whenever the corresponding interrupt bit fires. They read raw hardware data, update the relevant device model (keyboard, mouse, UART), and then forward the decoded event to the game controller via the game_handle_* family of functions.

These are thin glue routines; all game logic lives in controller/game.h.

void handle_mouse ( void  )

Handles a PS/2 mouse interrupt.

Accumulates incoming PS/2 bytes into the three-byte packet buffer. When a complete packet is ready it calls mouse_state_update and then game_handle_mouse. On the client VM the raw packet is also forwarded to the host via proto_send_mouse.

void handle_serial ( void  )

Handles a UART (serial) receive interrupt.

Calls uart_ih to drain the hardware FIFO into the software ring buffer, then feeds each byte through proto_feed_byte. When a complete message is assembled it is dispatched to game_handle_serial_msg.
