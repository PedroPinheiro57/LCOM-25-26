\doxysubsection{Detailed Description}
16550-\/compatible UART driver for COM1 serial communication. 

Configures the UART, 8-\/N-\/1, with FIFOs enabled and a 4-\/byte RX trigger threshold (matching the maximum protocol payload size). Received bytes are stored in a software ring buffer and consumed by uart\+\_\+recv\+\_\+byte.

Typical usage\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{uint8\_t\ irq\_bit;}
\DoxyCodeLine{uart\_init(\&irq\_bit);}
\DoxyCodeLine{\textcolor{comment}{//\ ...\ subscribe\ to\ IRQ4,\ point\ handler\ to\ uart\_ih()\ ...}}
\DoxyCodeLine{uart\_send\_byte(0x48);\ \ \ \textcolor{comment}{//\ 'H'}}
\DoxyCodeLine{uint8\_t\ b;}
\DoxyCodeLine{\textcolor{keywordflow}{if}\ (uart\_recv\_byte(\&b))\ \{\ \textcolor{comment}{//\ process\ b\ \}}}
\DoxyCodeLine{uart\_cleanup();}
