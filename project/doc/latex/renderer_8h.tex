\doxysubsection{Detailed Description}
Board and HUD rendering, sprite management, and explosion effects. 

Owns the lifetime of all in-\/game sprite and animated-\/sprite objects and exposes the drawing routines used by \doxylink{game_8h_a6491bcc04031f5d74d7c05e5bd9aad1c}{game\+\_\+draw} to compose each frame.

The renderer maintains a small state machine for the post-\/attack explosion animation\+: start\+\_\+explosion kicks it off, update\+\_\+animations advances it each tick, and renderer\+\_\+explosion\+\_\+finished signals when the sequence is complete so the game can resume input.
