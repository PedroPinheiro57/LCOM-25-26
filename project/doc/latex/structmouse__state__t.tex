\doxysubsection{Detailed Description}
Aggregated mouse state, updated every time a full packet arrives. 

The {\ttfamily clicked} and {\ttfamily released} fields are edge-\/triggered\+: they are only {\ttfamily true} for the single packet in which the left button transitions.
