\doxysubsection{Detailed Description}
Top-\/level declarations shared across the application entry point. 

The application is launched as either the {\itshape host} or the {\itshape client} VM. The role is parsed from the command-\/line arguments in {\ttfamily main()} and stored in a module-\/level variable that this header exposes.

Returns whether this instance is running as the client (non-\/host) role. 

The role is determined at startup from the command-\/line arguments. Use this anywhere a quick role check is needed without pulling in the full game state.

\begin{DoxyReturn}{Returns}
{\ttfamily true} if this VM was launched as the client, {\ttfamily false} if it is the host.
