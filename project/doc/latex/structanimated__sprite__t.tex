\doxysubsection{Detailed Description}
A sequence of sprite frames that animate in a loop. 

Frames are stored as an array of pointers to individually decoded \doxylink{structsprite__t}{sprite\+\_\+t} objects. Call \doxylink{sprites_8h_a9a6066de14062a59dc413cd131fd63fe}{anim\+\_\+sprite\+\_\+update} each tick to advance {\ttfamily cur\+\_\+pixmap} and \doxylink{sprites_8h_af99e43be627b7643a7324a2bfaa25995}{anim\+\_\+sprite\+\_\+draw} to blit the current frame.
