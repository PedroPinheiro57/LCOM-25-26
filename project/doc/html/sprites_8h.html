Detailed Description

Sprite loading, drawing, cursor management, and animated sprites.

Provides a thin abstraction over raw XPM pixel data. A sprite_t holds a decoded RGBA colour buffer that can be blitted to the framebuffer with optional 90° rotation.

The animated_sprite_t type wraps a sequence of up to eight sprite_t frames and advances through them one at a time on each call to anim_sprite_update.

The cursor subsystem maintains two pre-loaded cursor sprites (normal and hover) and renders the active one at an arbitrary pixel position.

◆ TRANSPARENT

#define TRANSPARENT   0xFFFFFE

Sentinel colour value treated as fully transparent.

Any pixel in a sprite whose colour equals this value is skipped during blitting so the background shows through.
