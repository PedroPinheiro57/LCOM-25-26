\doxysubsection{Detailed Description}
Sprite loading, drawing, cursor management, and animated sprites. 

Provides a thin abstraction over raw XPM pixel data. A \doxylink{structsprite__t}{sprite\+\_\+t} holds a decoded RGBA colour buffer that can be blitted to the framebuffer with optional 90° rotation.

The \doxylink{structanimated__sprite__t}{animated\+\_\+sprite\+\_\+t} type wraps a sequence of up to eight \doxylink{structsprite__t}{sprite\+\_\+t} frames and advances through them one at a time on each call to anim\+\_\+sprite\+\_\+update.

The cursor subsystem maintains two pre-\/loaded cursor sprites (normal and hover) and renders the active one at an arbitrary pixel position.
