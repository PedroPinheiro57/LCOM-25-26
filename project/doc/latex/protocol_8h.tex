\doxysubsection{Detailed Description}
Serial communication protocol for the two-\/\+VM Battleship session. 

Each message consists of a single-\/byte type tag followed by a fixed-\/ length payload (which may be zero bytes for simple signals). The receiver assembles bytes through proto\+\_\+feed\+\_\+byte until a complete message is available.

Message flow overview\+:
\begin{DoxyItemize}
\item Host and client exchange {\ttfamily MSG\+\_\+\+HELLO} / {\ttfamily MSG\+\_\+\+HELLO\+\_\+\+ACK} to establish the connection.
\item During ship placement the client mirrors its actions via {\ttfamily MSG\+\_\+\+SHIP\+\_\+\+PLACE} and signals completion with {\ttfamily MSG\+\_\+\+DONE\+\_\+\+PLACING}.
\item During combat, the active player sends {\ttfamily MSG\+\_\+\+ATTACK}; the host replies with the result embedded in the same message type.
\item Cursor positions are streamed with {\ttfamily MSG\+\_\+\+CURSOR} so each side can show where the other player is hovering. 
\end{DoxyItemize}
