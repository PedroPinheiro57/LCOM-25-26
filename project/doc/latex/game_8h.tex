\doxysubsection{Detailed Description}
Central game-\/state machine\+: structs, state tags, and controller API. 

The game is split across two VMs. The {\itshape host} owns the authoritative game state and drives the logic; the {\itshape client} forwards raw input over the serial link and renders whatever the host reports back.

All state transitions happen through the functions declared here. External code should treat \doxylink{structgame__t}{game\+\_\+t} as read-\/only and access it only via game\+\_\+get\+\_\+state.
